4
Instalación
AUTOMÁTICO · EL ORDEN IMPORTA
4.1
CasparCG — el servidor de gráficos
Queda registrado como servicio, escuchando AMCP en el puerto 5250.
4.2
MongoDB — la base de datos
MSI oficial en modo silencioso, como servicio de Windows. Va antes que el backend porque éste la necesita viva al primer arranque.
4.3
Backend — ejecutable único
Sin Python ni venv en la máquina del cliente. Genera su propia firma de sesiones al azar y activa la exigencia de licencia.
Se registra como servicio y se abre el puerto 9600 en el Firewall de Windows, para que el panel se alcance desde otros dispositivos.
4.4
Frontend — se compila y se limpia
Se genera el dist y se borra todo lo demás: código fuente, dependencias y configuraciones. En el equipo queda solo el compilado.
5
Configuración en el navegador
EL INSTALADOR CEDE EL CONTROL AQUÍ
5.1
Arrancan los servicios y se abre el navegador
El backend atiende en 0.0.0.0:9600 —por toda la red local— y sirve también la interfaz. Un solo puerto para todo.
El asistente muestra en pantalla la dirección con la que entrar desde otro equipo: http://<IP-del-servidor>:9600
Automático
5.2
Define la contraseña del usuario dueño

Acción del usuario
5.3
Indica la ruta del current.xml de MyLaps
El archivo de cronometraje. Debe ser ruta UNC (\\servidor\recurso), no una unidad mapeada: un servicio de Windows no ve las unidades de red mapeadas.
Si MyLaps aún no está encendido, la ruta se verifica contra el current.xml de demostración que viene incluido, y la real se ajusta después.
Acción del usuario

Ajusta canal de CasparCG, logo del cliente y ubicación del clima

Acción del usuario
FIN
✓ Race Core Studio operativo
El panel queda listo para trabajar. A partir de aquí ya no hace falta internet.

Un equipo hace de servidor. Todo lo demás entra por el navegador.

La máquina que ejecuta CasparCG se dedica solo a eso: gráficos, base de datos y API. No se trabaja sentado frente a ella. El panel se opera desde el navegador de cualquier dispositivo de la red —Windows, Linux, macOS o un iPad, que es el formato recomendado— apuntando a http://<IP-del-servidor>:9600. También desde el navegador del propio servidor, si hace falta.

Internet: obligatorio para instalar y renovar. Nunca para trabajar.

La licencia se valida offline en cada arranque: la vigencia viaja firmada dentro del propio token y se comprueba contra el reloj local. En el autódromo la red se cae, y el software no puede dejar de funcionar por eso. Si la licencia vence, hay un periodo de gracia antes de que el sistema se bloquee — y el bloqueo alcanza solo a los gráficos: el cliente sigue entrando al panel para poder renovar.
